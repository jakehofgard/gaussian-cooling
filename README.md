# Efficient Mass Matrix Estimation with Gaussian Cooling

This repository contains the experiments for *Efficient Mass Matrix Estimation
with Gaussian Cooling*. The experiments test how well Gaussian cooling estimates
a distribution's covariance. This estimate, called a preconditioner, rescales
the sampling problem to help the sampler move through directions with different
scales.

There are two groups of experiments:

- **Transformed Gaussians:** distributions whose exact covariance is known, so
  we can directly measure the accuracy of each method.
- **Lattice $\phi^4$:** non-Gaussian distributions on a square lattice. These
  experiments test how the methods behave as the lattice size, model parameters,
  and sampling budget change. See the [lattice experiment guide](phi4/PHI4_EXPERIMENTS.md)
  for commands and explanations of the figures.

All targets are generated by the code; no datasets need to be downloaded.

## Installation

Use Python 3.10 or newer. Run the commands below from the project directory:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

To check the installation, run a small version of each experiment group:

```bash
python experiment_transformed_gaussian.py --quick \
  --output-prefix results/gaussian_quick
python -m phi4.experiment_phi4_stage_convergence --quick \
  --output-prefix results/phi4_quick
```

The scripts create the output directory and save the plots as PDF files.
`--quick` uses smaller problems and fewer samples so you can check that the code
runs. Omit it to use the full experiment settings. `--output-prefix` sets the
directory and the first part of each output filename.

## Run the transformed-Gaussian experiments

```bash
python experiment_transformed_gaussian.py \
  --output-prefix figures/transformed_gaussian
```

This command compares three methods:

1. Gaussian cooling.
2. Covariance adaptation: repeatedly estimate the covariance and use it to
   rescale the sampler, without cooling the target.
3. Underdamped Langevin Monte Carlo (ULMC) without a learned rescaling.

Each method uses the same number of gradient evaluations, $nNK$, where $n$ is
the number of chains, $N$ is the number of steps per stage, and $K$ is the number
of stages. The third method runs each chain for $NK$ steps in one go.

The command produces two figures:

| File | What it shows |
| --- | --- |
| `transformed_gaussian_preconditioner_quality.pdf` | How the methods perform as the coordinate transformation stretches different directions by increasingly different amounts. |
| `transformed_gaussian_stage_convergence.pdf` | How the estimates improve from stage to stage for the hardest transformation, with an exact-covariance calculation for comparison. |

The target is constructed from $z\sim\mathcal N(0,\Sigma_0)$ by setting
$z=B^{1/2}x$. Its covariance is therefore $B^{-1/2}\Sigma_0B^{-1/2}$. The experiment
increases the condition number of $B$ while keeping its eigenvectors fixed.

To change the problem or the sampling budget, use the following options:

| Options | What they change |
| --- | --- |
| `--dimension`, `--base-condition-number`, `--kappas` | The target dimension, the condition number of $\Sigma_0$, and the condition numbers to test for $B$. |
| `--chains`, `--steps`, `--stages` | The sampling budget $n$, $N$, and $K$. |
| `--repeats`, `--convergence-repeats` | The number of independent runs for the first and second figures, respectively. |
| `--seed`, `--dtype` | The random seed and numerical precision. |

For example:

```bash
python experiment_transformed_gaussian.py \
  --chains 512 --steps 128 --stages 12 --repeats 12 \
  --output-prefix figures/gaussian_custom
```

Use `python experiment_transformed_gaussian.py --help` to list all options.
Values supplied on the command line override the corresponding `--quick`
settings. Each lattice experiment has its own options and defaults, described
in [phi4/PHI4_EXPERIMENTS.md](phi4/PHI4_EXPERIMENTS.md).

## What the quality plots measure

The plots measure how well the estimated covariance rescales the target.
Specifically, they report the relative condition number

```math
\kappa_{\mathrm{rel}}(\widehat\Sigma,\Sigma)
=\kappa\!\left(\widehat\Sigma^{-1/2}\Sigma\widehat\Sigma^{-1/2}\right),
```

where $\widehat\Sigma$ is the estimate and $\Sigma$ is the target covariance.
A smaller value is better; one is ideal. The Gaussian experiments use the exact
target covariance. The lattice experiments estimate it from a separate set of
samples, so those comparisons also depend on the accuracy of the reference.

| File or directory | Contents |

For readers using the sampling functions directly: they return the final sample
from each independent chain. `sample_covariance` divides by $n$, rather than
$n-1$. Large lattice experiments store covariance information in Fourier space
to avoid constructing a full covariance matrix. The experiment scripts set
precision and random seeds; the sampling library leaves these choices to its
caller. Small numerical differences can occur across hardware and JAX versions.
